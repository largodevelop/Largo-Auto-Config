# Largo Auto Config

Трей-приложение от **Largo Develop**: один общий профиль CFG + настроек Dota 2, который подставляется при смене Steam-аккаунта.

## Возможности

- **Автозамена** — при смене Steam-аккаунта (и один раз при запуске Dota) применяется сохранённый профиль
- **Скопировать настройки с аккаунта** — полный снимок `userdata/<id>/570` (`remote` + `local`) в глобальный профиль
- **CFG** — выбор / drag-and-drop своего `.cfg` (например `sandalik.cfg`) + запись в `autoexec.cfg`
- **Настройки** — выбор / drag-and-drop папки `570`
- Работает в трее, безрамочное окно в стиле Largo Develop
- Окно видно в Alt+Tab и на панели задач

Инжект **не крутится по таймеру**: один раз на смену аккаунта / на процесс Dota, чтобы внутриигровые настройки не откатывались.

## Запуск из исходников

```bash
pip install -r requirements.txt
python app/main.py
```

Опционально скопируй `config.example.json` → `config.json`.

## Сборка EXE

```bash
pip install -r requirements.txt pyinstaller
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Готовый файл: `dist/LargoAutoConfig.exe`.

## Как пользоваться

1. Запусти приложение (или exe).
2. При желании укажи свой `.cfg` (иконка CFG) и/или папку `570` (иконка настроек).
3. Нажми **Скопировать настройки с аккаунта** — снимок текущего Steam-аккаунта в профиль приложения.
4. Включи **Автозамена**.
5. Переключай Steam-аккаунты / запускай Dota — профиль применится один раз.

### Где лежит папка `570`

```
C:\Program Files (x86)\Steam\userdata\<AccountID>\570
```

`AccountID` — числовая папка твоего аккаунта. Внутри обычно есть `remote` и `local`.

Если Dota установлена в другой библиотеке Steam, приложение находит её через `libraryfolders.vdf`.

## Структура

```
app/           — код приложения
assets/        — логотип Largo
defaults/      — запасной autoexec
profiles/      — локальные профили (не в git)
config.json    — локальные настройки (не в git)
```

## Требования

- Windows 10/11
- Steam + Dota 2
- Python 3.11+ (только для запуска из исходников / сборки)
